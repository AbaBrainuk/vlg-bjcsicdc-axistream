  这是比赛后凭借记忆复刻并完成的比赛赛题的相关文件。
  事情是这样的，我准备了很久的比赛，2026年北京市大学生集成电路设计比赛，因为我的睡眠不足，毁了。比赛当天只睡了三个半小时，导致比赛进行到后面时，我已经完全处于猪脑过载的状态了--看到一段代码，每个单词都认识，但是连起来不知道啥意思，而且完全无法进行各种信号的时序的思考了，所以即使我完成了比赛时基本完成了全部模块的代码，考虑好了思路，但是实在没有脑子去调试修改了，后面我的心态已经爆炸，直接随便写了份报告提交了，甚至当时想直接交白卷来着。显然，对于这个比赛来说，我的一切努力都功亏一篑了。
  比赛结束后，充分休息好后，就想在不借助ai和搜索引擎的情况下,试着再次完成赛题，然后就花了几个小时，凭借记忆完成了赛题，也就是上面的所有文件了。

  比赛的题目大致是这样的：

  需要设计一个计算模块，实现对传入的4x4矩阵的乘法和加法，乘法为哈达玛积,加法为矩阵内每个元素相加。为了实现这目标，需要设计三个模块，分别为解码，求积，求和模块。这些模块的端口定义不得更改，只能增加必要的信号，必须是流式传输，具体的要求可以看看代码里的模块定义。注释由中文写成。输入信号为简化的AXI_stream信号。

  不过这是我自己浓缩之后的题意，实际的赛题很罗嗦，而且还有很多冗余矛盾不清楚的描述，比如说，对于乘法模块，实践过程中，为了效率，根本不需要先存储再运算，但是赛题原题描述要求接受完再运算什么的，这些也造成了我比赛时原本的猪脑更困惑了。。。顺便我真想吐槽，其实个人感觉如果只规定了顶层必须要用流式传输，后续的模块没要求，其实可以很快很轻松的用流水线完成这一切，效率甚至会更高，但是赛题必须要求全部为流式传输，就很难受。

  我个人不是通信专业的，也不学相关的课，学习verilogHDL，FPGA，以及这些相关知识，只是纯粹个人兴趣而已，所以可能即使是赛后清醒状态下写的，也可能有各种错误(-v=)。总之，希望这些代码能够给未来想打这个比赛或者类似比赛的人一个参考吧，以及赛前一定要好好休息，不要复刻我的遗憾。
